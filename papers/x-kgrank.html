Can recommendations be useful, personal, and explainable?

X-KGRank combines graph-based recommendation with grounded language-model explanations, using user-item relationships as evidence instead of asking an LLM to explain from memory.

Read the paper ↗View on arXiv ↗

The problem in one minute

A recommendation can be accurate but impossible to trust if the user cannot see why it was chosen. A language model can produce a fluent explanation but invent facts or ignore the user’s actual history. X-KGRank keeps the ranking model and uses a knowledge graph to provide evidence for the explanation.

How the system works

The pipeline trains a LightGCN ranker with SBERT-initialized movie representations, mines graph structure with node2vec and community detection, and retrieves candidate-specific paths for long-tail items. Popular items use a cheaper route; less-popular items receive graph-grounded context.

Measured result

On MovieLens-1M under a 99-sample evaluation protocol, X-KGRank improved ranking quality over a strong popularity baseline. The graph contains 9,762 nodes and 999,264 edges, while popularity-selective routing limits expensive graph retrieval to 1,855 long-tail items—roughly half the catalog.

Additional findings: NDCG@20 improved by 15.6% and MRR by 14.6%. In a 16-case explanation comparison, Qwen2.5-1.5B reached a heuristic quality score of 0.97 versus 0.94 for Mistral-7B, but qualitative review found that the smaller model was more prone to factual fabrication.

Why the result matters

The key idea is selective grounding. Not every recommendation needs an expensive graph lookup. Popular items may already be familiar to a language model, while long-tail items benefit more from explicit behavioral evidence. This keeps the explanation layer grounded without applying the full retrieval cost to every candidate.

Limitations

The explanation-quality score is a heuristic proxy rather than a human factuality judgment. The study also uses a sampled 99-negative evaluation protocol and a small 16-case LLM explanation comparison, so the ranking results are stronger evidence than the explanation-quality comparison.
