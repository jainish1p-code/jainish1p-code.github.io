Project 01 · Autonomous driving · Graph VQA

Can connected reasoning help a vehicle plan?

DriveLM Graph Reasoning studies whether a vision-language model makes better driving-planning decisions when it receives connected perception and prediction context—not only a single front-camera image.

View code on GitHub ↗ Ask me about it

The idea in one minute

A person can make a better driving decision when they know what objects are present, what those objects may do next, and how those facts are connected. This project tests whether the same principle helps a vision-language model answer planning questions.

Input Front-camera scene What does the vehicle see?
→
Reasoning context Perception → prediction → planning graph What is connected to what?
→
Output Driving-planning answer Stop, brake, maintain speed, or accelerate

Experimental design

Three conditions separate the effect of graph context from the effect of the image itself.

Image only

The model receives the front image and planning question. This is the baseline.

Graph-connected context

The model receives upstream perception and prediction answers linked to the planning question.

Measured result

On 3,673 validation planning records, adding gold graph-linked parent answers improved token F1 from 0.755 to 0.846 and ROUGE-L from 0.748 to 0.834. The largest gain came from braking decisions, where F1 increased from 0.258 to 0.701. This is an oracle-context result; predicted parent context is the next test.

What I built

The pilot uses DriveLM-CARLA question-answer data and corresponding PDM-Lite CARLA frames. I verified a 2,730-frame pilot with 2,098 training frames and 632 validation frames, then structured the evaluation around route-level splits.
